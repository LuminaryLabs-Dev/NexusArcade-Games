# Springjack Express

A five-minute launch-and-bounce momentum arcade prototype. Time the spring meter, steer into wind-up critters and slam from above; choose one of three related two-tier upgrade branches. Reach 65 delivery gates before the closing bell. Original clockwork courier and city visuals are authored with Canvas; procedural sound uses Web Audio. No external asset dependencies or copied reference artwork.

Run `build/index.html` in a modern browser. Space launches or slams; A/D or arrows steer; Escape pauses; M toggles mute; touch controls are on screen. Settings, records, restart, results and exit are game-owned.

Source and build are identical. This is a registry-pending prototype under NXA-000018; no catalogue IDEA identity was located or assigned. See evidence/validation.json for the tested digest and limitations. Not a release or a native Builder Kit qualification.
