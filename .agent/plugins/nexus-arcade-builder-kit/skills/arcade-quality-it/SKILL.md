# arcade-quality-it

Review the exact verified payload hash using tests and actual visual/interaction evidence. Assess clarity, agency, feedback, challenge, recovery, coherence and accessibility. Each verdict needs an observation and evidence files. Label the review inferred-human-factors; never claim human playtesting or enjoyment without actual evidence. Wrong assumptions return to inspect; implementation or design defects return to plan. Missing hardware, permission or evidence blocks. A pass only unlocks authorized registration.
