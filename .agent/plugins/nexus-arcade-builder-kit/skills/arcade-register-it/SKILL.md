# arcade-register-it

Require a passing review bound to unchanged payload bytes and explicit registration authority. Preserve all other releases. Register immutable per-file hashes and sizes in NexusArcade-Games, update the approved Website consumer pin and route only when included in scope, and verify actual install, launch and close. Use approved main branch commits and check remote state. A repository commit alone is not proof of Website deployment or playable installation. Missing evidence remains blocked.
