Preparation moves Raw Ideas → Filtered Profiles → Profile Prompts → Curated Prompts. Archived Ideas retains rejected/deferred identity and history. The source repository is a later implementation surface. Curated prompts do not establish working games, and game candidates do not establish accepted/public releases.

For code already returned, recover its existing identity and continue conversion. Do not ask the user to choose a writer again. Ask only for a genuinely missing decision that changes implementation or safety.
